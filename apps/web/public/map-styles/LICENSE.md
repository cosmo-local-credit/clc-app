# CLC Dark Liberty map style

`liberty-dark.json` is a modified snapshot of OpenFreeMap's Liberty style,
retrieved from <https://tiles.openfreemap.org/styles/liberty> on 2026-10-27.
It retains OpenFreeMap's vector-tile, sprite, and glyph endpoints while applying
CLC's dark-map palette.

The OpenFreeMap project is MIT licensed. Liberty is derived from OSM Liberty and
OSM Bright: its code is available under the BSD 3-Clause License and its visual
design under Creative Commons Attribution 4.0. OpenFreeMap's complete notices
are at <https://github.com/hyperknot/openfreemap/blob/main/LICENSE.md>.

Map data is from OpenStreetMap. The application's visible MapLibre attribution
control continues to credit OpenFreeMap, OpenMapTiles, and OpenStreetMap.
